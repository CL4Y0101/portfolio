# Portfolio Images

Taruh foto profil kamu di folder ini dengan nama:

```text
profile.jpg
```

File `profile.jpg` akan otomatis dipakai untuk foto di profile card kanan atas dan visual landing page.

Rekomendasi foto:

- Format: JPG
- Rasio: portrait atau square
- Ukuran: minimal 800 x 800 px
- Background: bersih dan profesional

Kalau ingin memakai nama atau format lain, ubah path `src/img/profile.jpg` di `index.html` dan `style.css`.
